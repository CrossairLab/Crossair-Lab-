## Pubblicazione
1. Repository: `CrossairLab/Crossair-Lab-`.
2. In **Settings → Pages**, scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi salva.
3. Attendi la pubblicazione. L'URL previsto è `https://crossairlab.github.io/Crossair-Lab-/`.
4. Condividi l'URL. Gli amici possono aprirlo e installarlo da Edge con **… → App → Installa questo sito come app**.

La pagina usa HTTPS. Non inserire credenziali o chiavi segrete nel sito statico. Agenti e mappe caricano dati/immagini online; preferiti e mirini salvati restano nel browser locale e non si sincronizzano.
